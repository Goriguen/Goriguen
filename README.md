  ## ⚡ Problemas reales que resolví (Troubleshooting)

  - **Seguridad e Infraestructura (Auditoría SSH)**: Audité la configuración SSH de mi VPS y detecté que el acceso mediante contraseña seguía habilitado. Desactivé password authentication, bloqueé el acceso de root y configuré autenticación mediante claves SSH.

  - **Arquitectura de CI/CD (Mitigación de Riesgos)**: Separé los despliegues de Demo y Producción mediante GitHub Actions. Demo tiene despliegue automático; Producción requiere aprobación manual antes del deploy.

  - **Troubleshooting de Base de Datos (Integridad en MySQL)**: Detecté inconsistencias en registros legacy después de cambios en el esquema. Analicé los datos directamente en MySQL mediante un túnel SSH, identifiqué los registros afectados y saneé la información.
